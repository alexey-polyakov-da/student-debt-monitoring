# Student Debt Monitoring — автоматизация контроля задолженности

## О проекте

Python-проект для автоматического контроля задолженности студентов по рассрочкам на обучение.

Программа получает данные из трёх листов Google Sheets через API, сопоставляет информацию по идентификаторам студентов, рассчитывает просроченные платежи и формирует текстовый отчёт.

## Бизнес-задача

Автоматизировать контроль своевременности платежей и выявление студентов с задолженностью без ручной проверки таблиц.

## Технологии

- Python
- Google Sheets API
- gspread, oauth2client
- datetime, json, argparse
- Работа со словарями и файлами

## Алгоритм обработки

1. Получение данных из трёх листов Google Sheets.
2. Объединение информации по `student_id`.
3. Отбор студентов с рассрочкой.
4. Определение просроченных платежей на 01.03.2023.
5. Расчёт количества пропущенных платежей с интервалом 183 дня.
6. Расчёт задолженности с учётом оставшейся суммы рассрочки.
7. Формирование отчёта `student_debt_report.txt`.

## Результаты

- Обработаны данные 500 студентов.
- Загружены 253 записи о датах платежей и 253 финансовые записи.
- Выявлены 166 студентов с задолженностью.
- Автоматизировано формирование отчёта о должниках.
- Реализованы два режима работы: через Google Sheets API и на локальных демонстрационных данных.

## Установка и запуск

Необходим Python 3.

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

### Демонстрационный режим

Не требует доступа к Google Sheets:

```bash
python main.py --demo
```

### Основной режим — Google Sheets API

Для подключения требуется файл `creds.json` с учётными данными сервисного аккаунта Google, которому предоставлен доступ к таблице.

Файл необходимо разместить в папке проекта. Он не включён в репозиторий по соображениям безопасности.

Запуск:

```bash
python main.py
```

Результат сохраняется в `student_debt_report.txt`.

## Пример отчёта

```text
Студент Иванов И.И. - долг 50000 рублей
Студент Петров П.П. - долг 300000 рублей
```

*Пример сформирован на демонстрационных данных.*

## Практическая ценность

Проект демонстрирует интеграцию Python с внешним API, обработку данных из нескольких источников, автоматический расчёт финансовых показателей и формирование отчётности.

Логика получения данных отделена от логики расчёта задолженности, что позволяет использовать разные источники и независимо проверять обработку данных.
